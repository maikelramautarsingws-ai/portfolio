MyQ Secure Printing

The last project in 2021 i worked on was implementing a software technology on a server which allowed multiple printers on the network to be combined together. This allowed secure printing and scanning from any location within the network even from location to location. The tech company which provided the software was MyQ-Solutions. It was my first experience working with them and it was a great opportunity. This software was a project intended to be used for an Oil & Gas Company in Suriname. Though this project didn't get the go ahead in the final stages i learned a lot out of this and had fun with it when i had set this up as a demo in a physical network with multiple printers, card-readers.
